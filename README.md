# DaoFuse

DaoFuse orchestrates event-driven, asynchronous processing of data streams through a dynamically scalable, real-time data management controller.

DaoFuse is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/DaoFuse.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

DaoFuse is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
